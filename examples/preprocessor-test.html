XRender 预处理器测试

测试功能：

  • SCSS 预处理器支持 (lang="scss")
  • Less 预处理器支持 (lang="less")
  • CSS Modules 支持 (module)
  • 作用域样式支持 (scoped)

使用说明：

<style lang="scss" scoped>
  $primary-color: #3498db;
  
  .container {
    color: $primary-color;
    
    &:hover {
      opacity: 0.8;
    }
  }
</style>

<style lang="less" scoped>
  @primary-color: #e74c3c;
  
  .container {
    color: @primary-color;
    
    &:hover {
      opacity: 0.8;
    }
  }
</style>

<style module>
  .container {
    color: #9b59b6;
  }
</style>
