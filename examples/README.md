# XRender 示例项目

本目录包含 XRender 框架的完整示例项目，帮助您快速了解和使用 XRender 的各种功能。

## 示例列表

### 1. 基础示例 (basic-example.html)
展示 XRender 的基础功能，包括：
- 组件定义和使用
- 数据响应式
- 事件处理
- 列表渲染
- 条件渲染

**运行方式：** 直接在浏览器中打开 `basic-example.html`

### 2. 待办事项应用 (todo-list/)
一个完整的待办事项管理应用，展示：
- 响应式数据管理
- 计算属性
- 事件处理
- 列表操作（添加、删除、切换状态）
- 过滤功能
- 统计信息

**运行方式：** 直接在浏览器中打开 `todo-list/index.html`

**核心特性：**
- 使用计算属性实时统计待办事项
- 支持全部、进行中、已完成三种过滤状态
- 完整的 CRUD 操作
- 美观的 UI 设计

### 3. 表单处理 (form/)
用户注册表单示例，展示：
- 表单数据绑定
- 表单验证
- 错误提示
- 实时预览
- 表单重置

**运行方式：** 直接在浏览器中打开 `form/index.html`

**核心特性：**
- 实时表单验证
- 多种表单控件支持（文本、邮箱、电话、数字、单选、多选、文本域）
- 错误信息显示
- 实时数据预览

### 4. 路由示例 (router/)
多页面应用示例，展示：
- 路由配置
- 动态路由参数
- 编程式导航
- 路由守卫
- 嵌套路由

**运行方式：** 需要在本地服务器环境中运行（如使用 http-server）

**核心特性：**
- 多个页面（首页、用户管理、产品中心、关于我们）
- 动态路由（用户详情、产品详情）
- 导航菜单
- 404 页面处理

**注意：** 由于使用了 history 模式，建议使用本地服务器运行：
```bash
# 安装 http-server
npm install -g http-server

# 在 examples/router 目录下运行
cd examples/router
http-server -p 8080
```

### 5. 国际化 (i18n/)
多语言支持示例，展示：
- 多语言切换
- 文本翻译
- 语言包管理
- 动态内容翻译

**运行方式：** 直接在浏览器中打开 `i18n/index.html`

**核心特性：**
- 支持中文、英文、日文三种语言
- 实时语言切换
- 完整的翻译系统
- 表单验证的多语言支持

## 如何使用示例

### 直接打开
对于简单的示例（basic-example.html、todo-list、form、i18n），可以直接在浏览器中打开对应的 HTML 文件。

### 使用本地服务器
对于需要路由功能的示例（router），建议使用本地服务器：

```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js http-server
npx http-server -p 8080

# 使用 PHP
php -S localhost:8080
```

然后在浏览器中访问 `http://localhost:8080`

## 学习路径

1. **基础示例** - 了解 XRender 的基本概念和 API

4. **路由示例** - 学习单页应用的路由管理
5. **国际化** - 了解多语言支持的实现
